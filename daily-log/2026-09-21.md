### System Improvement Suggestion

> **Create a 2-field "post done" shortcut in your phone's notes or shortcuts app.** The pattern across 22+ misses is identical: draft exists, intent exists, action fails. The failure point is not writing — it's the transition from LinkedIn tab to terminal to run `./confirm-post.sh`. Create a phone shortcut (iOS Shortcuts or Android tasker) or a pinned note with two fields: "Posted? Y/N" and "URL." When you post, tap the shortcut → paste the URL → it calls `confirm-post.sh` via a Shortcut/webhook (or just reminds you to run it). The goal is to make confirming a post as frictionless as the post itself. Alternatively, add one line to `confirm-post.sh` that prompts for the URL interactively so you can run a single command from the phone terminal (Blink/Termius) without typing the URL as a CLI arg. 30-minute setup, permanent fix for post tracking.
