## Post Text

200 applicants screened in 40 minutes.

No HR coordinator. No spreadsheet. No 11pm resume pile.

Here's the Make + OpenAI pipeline we built for a 30-person agency:

**The Problem:**

Every open role = 150-200 applicants → 8-10 hours of manual resume review → burned-out hiring manager → rushed decisions → bad hires.

At $50/hr that's $400-500 just to build a shortlist. Before a single interview.

**The System (5 steps):**

1. Applicant submits form → data hits Make
2. Make sends resume text + role criteria to GPT-4o
3. GPT scores on 5 dimensions: skills match, experience relevance, growth trajectory, communication quality, culture fit signals
4. Score + 2-line summary → Airtable row + Slack alert for any score ≥ 75
5. Hiring manager reviews the top 10. Final call is still human.

**The Result:**

→ 200 applicants → shortlist in 40 minutes
→ Hiring manager time: 10 hours → 45 minutes
→ Spot-checked 50 rejected applications manually — GPT's scoring held up every time

The real insight: AI doesn't replace judgment. It removes the exhaustion that clouds it.

When you're not reading resume #137 at 11pm, you make better calls on resume #1-10.
