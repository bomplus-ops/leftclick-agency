### System Improvement Suggestion

> **Build a one-command post launcher.** Every missed post has the same failure mode: the draft exists, it's ready, but "copy-paste it into LinkedIn" is 8 steps across 3 windows and gets skipped. Create a shell script (`post-today.sh`) that: (1) reads the current day's `*-post.md` draft, (2) copies the draft section to the clipboard (`xclip` or `pbcopy`), and (3) opens `linkedin.com/feed/` in the browser. That collapses 8 steps to 1 command. The draft is already in your clipboard when LinkedIn opens. This won't auto-post (LinkedIn's API requires approval app status), but it removes all friction between "I should post" and "I am typing the post." Saturday is a good day to build this — it'll be live before Monday's Sep 1 post.
