The friction point is not motivation — it's context-switching. Every draft lives in `daily-log/YYYY-MM-DD-post.md`, mixed in with operational logs. Create a `post-ready/` folder. Bot drops drafts there when they're scheduled. Human opens `post-ready/` → sees one file → copies it → LinkedIn native scheduler → done.
